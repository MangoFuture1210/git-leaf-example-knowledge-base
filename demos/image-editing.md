# Live image editing

This page uses the OpenPeek application icon so the image and its surrounding text both belong to the
project.

## Markdown image

Select this image in **Live** to reveal the image toolbar.

![OpenPeek application icon](../assets/openpeek.png)

When an explicit width, alignment, or caption is applied, OpenPeek writes a controlled HTML image line
whose source remains visible in Source.

## Controlled HTML image

<img src="../assets/openpeek.png" alt="OpenPeek application icon centered for the image demo" width="480" data-align="center" data-caption="OpenPeek is the human interface over a local Git repository.">

Try changing the width, moving the image left or center, and updating the caption. Unsupported HTML
attributes are not part of the safe image contract.
