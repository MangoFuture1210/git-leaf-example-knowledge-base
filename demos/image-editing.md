# Live image editing

This page uses the OpenGlance application icon so the image and its surrounding text both belong to the
project.

## Markdown image

Select this image in **Live** to reveal the image toolbar.

![OpenGlance application icon](../assets/openglance.png)

When an explicit width, alignment, or caption is applied, OpenGlance writes a controlled HTML image line
whose source remains visible in Source.

## Controlled HTML image

<img src="../assets/openglance.png" alt="OpenGlance application icon centered for the image demo" width="480" data-align="center" data-caption="OpenGlance is the human interface over a local Git repository.">

Try changing the width, moving the image left or center, and updating the caption. Unsupported HTML
attributes are not part of the safe image contract.
