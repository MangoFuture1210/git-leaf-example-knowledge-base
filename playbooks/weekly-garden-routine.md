# Weekly garden routine

Use this checklist at the start and end of each volunteer session.

## Before opening

- [ ] Check the weather and any safety notices.
- [ ] Unlock the tool cabinet and inspect shared tools.
- [ ] Fill the drinking-water jug.
- [ ] Read the current project notes.

## Before leaving

- [ ] Return and count shared tools.
- [ ] Record plants that need follow-up.
- [ ] Remove rubbish and close the compost lid.
- [ ] Lock the cabinet and gate.

## When something unexpected happens

Write a short note in the relevant project page. If the situation changes a lasting rule, add a decision
record instead of silently rewriting history.
